# Ground

Gaborone does not have a dedicated Ground frequency, as such all Ground responsibilities are assumed by Khama Tower (FBSK_TWR). Under no circumstances should FBSK_GND ever be opened without prior approval from staff.
## Visual Flight Rules (VFR) Aircraft.

On initial call with SMC, the VFR aircraft is expected to provide:

* Aircraft Registration, if the callsign used is not the aircraft registration
* Aircraft Type
* Persons on Board
* Fuel Endurance
* Intentions

Once this data has been received by the SMC controller, the controller shall then issue the QNH, Active, and if operating on a FPL, a discrete squawk code.

!!! info "VFR Phraseology"
    "A2MNO, start up approved, Runway XX in use, QNH 1015, report ready for taxi."

## Restrictions

Gaborone is only able to accommodate up to Code C aircraft.

!!! warning 
    Aircraft above Code C should be advised that there is no guranteed wingtip clearance provided.

| Aprons | Restricted to |
| :---------: | :---------: |
| GA Maintenance | Code C (max 36m wingspan)
| Maintenance Apron | Code C (max 36m wingspan)

SMC controllers should remain vigilant at all times.

**An aircraft must be squawking their assigned ASSR code provided in the clearance before pushback clearance is issued. If this is not the case, the SMC controller must instruct the pilot to do so BEFORE any push clearance is issued.**

!!! info "Pushback Phraseology"
    "(callsign), push and start approved, face W / E , QNH (QNH)."

### Arriving Aircraft
Assuming that the arriving aircraft has vacated the runway, you would issue taxi instructions to a stand. If it is quiet, you may ask which stand the aircraft prefers and then clear it to that stand via B and/or L, E, or F.
